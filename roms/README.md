# ROM files

Use your own unmodified US copy of Rocket: Robot on Wheels. The builder asks
you to select it and saves a private working copy under `build/private/`.
Do not commit or distribute the ROM.

- Game code: `NSUE`
- Size: 12 MiB (`0xC00000` bytes)
- Canonical SHA-1: `622D71A44DA0B81EA68092CAC9198C66154A4F4A`

`.z64`, `.v64` and `.n64` byte orders are accepted.

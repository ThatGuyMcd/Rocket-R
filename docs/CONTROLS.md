# Controls

You can use a keyboard, a controller, or both. Android also has touch controls.
Open **Controls** in the launcher or in-game settings to change your setup.

## Default keyboard controls

| N64 control | Keyboard |
| --- | --- |
| Analogue stick | W, A, S, D |
| A | Space or X |
| B | Z or Left Ctrl |
| Z trigger | Left or Right Shift |
| Start | Enter |
| D-pad | Arrow keys |
| L / R | Q / E |
| C-Up / C-Down / C-Left / C-Right | I / K / J / L |

F1 or Escape opens settings. F11 or Alt+Enter switches fullscreen.
The F1/F11 bindings can be changed in **Shortcuts**. Escape and Alt+Enter
remain available even if you change those bindings.

## Controller Studio

Open **N64 Controls**, then select a button on the controller diagram or choose
a group above it. The card shows the selected N64 control and its current inputs.
Click an input to replace it. **Extra inputs** opens the second keyboard and
controller slots.

Release any held button before pressing the new input, and let the stick return
to centre before assigning an axis. Escape cancels the assignment. Backspace,
Delete or **Remove Input** clears it. Unplugging the selected controller or
switching away from the window also cancels an unfinished assignment.

If that input is already assigned elsewhere, choose **Swap Inputs**, **Share
Input**, or **Cancel**. Swap is available for a single conflicting assignment.
Changes save as you make them.

Controller face buttons are named by position: bottom, right, left and top.
This avoids confusion between controllers with different printed letters.
Choose the controller you want to use on the **Controller** tab.

## Guided Setup

Select **Guided Setup** if you'd rather work through each control in order.
The guide covers all 18 inputs, including the analogue directions, C buttons
and D-pad. Use Next and Back to move through them, then review your setup.
You can leave the guide at any time. Controls you skip keep their assignments.

## Testing and stick settings

**Test Inputs** highlights the N64 inputs your setup produces without passing
them to the game. Escape, controller Back/Select or **Done Testing** ends the test.
Leaving N64 Controls or closing the overlay also ends it.

Use the **Stick** tab to adjust deadzone, sensitivity, response and inversion.
Controller selection and Rumble Pak settings are on **Controller**.
Restoring N64 bindings does not reset those other settings.

## Android touch controls

The on-screen stick and buttons support simultaneous touches, so you can move
and jump together. Tap **Settings** or press Android Back to open the overlay.
Tap **Return to Game** or press Back again to continue playing.

**Hide Controls** removes the gameplay buttons when you're using a controller.
Settings and **Show Controls** stay on screen. The device's volume buttons
adjust media volume.
